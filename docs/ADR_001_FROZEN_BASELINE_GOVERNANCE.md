# ADR-001 — FROZEN BASELINE & ARCHITECTURAL GOVERNANCE PROTOCOL

**Status:** Accepted & Frozen  
**Date:** August 6, 2026  
**Context:** Missions 001, 001A, 002, and 003 constitute the complete frozen baseline for the Atmospheric Complexity Framework (ACF).  

---

## 1. Decision & Governance Policy

1. **Frozen Baseline Lock**: MISSIONS 001, 001A, 002, and 003 are permanently frozen as the reference engineering baseline for ACF.
2. **ADR / RFC Requirement**: Any future modification to the baseline roadmap, architecture, or core APIs MUST be justified via an **Architecture Decision Record (ADR)** or a **Request for Change (RFC)** document.
3. **Traceability Guarantee**: Every new feature or sprint task must trace directly back to a approved requirement or gap ID registered in the MIP baseline.
