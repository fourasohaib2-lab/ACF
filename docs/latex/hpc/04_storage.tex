\section{Scientific Storage Infrastructure}


ACF manages very large volumes of Earth system data.



Storage layers:


\begin{itemize}

\item Fast SSD storage

\item Parallel file systems

\item Long-term archives

\item Cloud object storage

\end{itemize}



Supported technologies:


\begin{itemize}

\item NetCDF archives

\item GRIB repositories

\item HDF5 databases

\end{itemize}
