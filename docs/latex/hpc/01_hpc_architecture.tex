\section{ACF High Performance Computing Architecture}


Atmospheric simulation requires extremely large computational
resources because the Earth system contains multiple interacting
components.



The ACF HPC architecture includes:


\begin{itemize}

\item Compute nodes

\item GPU acceleration nodes

\item High-speed interconnect network

\item Parallel storage systems

\item Scientific workflow management

\end{itemize}
