\section{ACF Cryosphere Architecture}


The ACF cryosphere module represents frozen components of the
Earth system and their interactions with atmosphere, ocean and
land.



The system integrates:


\begin{itemize}

\item Snow observations

\item Glacier models

\item Sea ice models

\item Permafrost analysis

\item Satellite monitoring

\item Climate simulations

\end{itemize}



Cryosphere interaction:


\begin{equation}
Atmosphere
\leftrightarrow
Cryosphere
\leftrightarrow
Ocean
\end{equation}
