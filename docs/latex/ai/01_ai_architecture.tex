\section{ACF Artificial Intelligence Architecture}


The ACF AI engine integrates machine learning technologies
with atmospheric sciences.



The architecture contains:


\begin{itemize}

\item Data preparation layer

\item Feature extraction layer

\item AI model layer

\item Validation layer

\item Operational inference layer

\end{itemize}



AI workflow:


\begin{equation}
Data
\rightarrow
Features
\rightarrow
Model
\rightarrow
Prediction
\rightarrow
Decision
\end{equation}
