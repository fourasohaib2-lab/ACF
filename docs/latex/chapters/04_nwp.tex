\section{Numerical Weather Prediction}

Numerical Weather Prediction (NWP) solves the atmospheric
governing equations using numerical methods.

The main components are:

\begin{itemize}
\item Atmospheric model
\item Initial conditions
\item Boundary conditions
\item Numerical discretization
\item Data assimilation
\end{itemize}


\section{Model Grid}

The atmosphere is discretized using:

\begin{itemize}
\item Horizontal grids
\item Vertical coordinates
\item Time stepping
\end{itemize}
