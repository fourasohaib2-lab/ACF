\section{Space Weather Module}

ACF includes a space environment monitoring capability.

The module analyzes interactions between the Sun and Earth.



\section{Solar Activity}

Main parameters:

\begin{itemize}
\item Solar wind velocity
\item Solar magnetic field
\item Sunspot activity
\item Solar flares
\item Coronal mass ejections
\end{itemize}



\section{Geomagnetic Storms}

Solar disturbances can affect:

\begin{itemize}
\item Satellites
\item GPS systems
\item Communication networks
\item Electrical grids
\end{itemize}
