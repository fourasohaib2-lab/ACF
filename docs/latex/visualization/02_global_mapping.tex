\section{Global Mapping Engine}


The ACF mapping system provides global Earth visualization.



Supported elements:


\begin{itemize}

\item Political boundaries

\item Terrain elevation

\item Oceans

\item Atmospheric fields

\item Risk zones

\item Observation networks

\end{itemize}



Map projections:


\begin{itemize}

\item Geographic projection

\item Lambert projection

\item Polar projection

\item Mercator projection

\end{itemize}
