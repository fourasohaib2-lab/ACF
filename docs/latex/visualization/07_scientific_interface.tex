\section{Scientific User Interface}


The ACF interface is designed for scientists and operational
meteorologists.



Main components:


\begin{itemize}

\item Interactive maps

\item Data explorer

\item Parameter selection

\item Vertical profiles

\item Time control

\item Alert panels

\end{itemize}



The interface supports:


\begin{itemize}

\item Forecast analysis

\item Research activities

\item Operational decision making

\end{itemize}
