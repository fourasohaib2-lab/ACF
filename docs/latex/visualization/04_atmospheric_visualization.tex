\section{Atmospheric Data Visualization}


ACF represents atmospheric variables in three dimensions.



Visualized parameters:


\begin{itemize}

\item Temperature fields

\item Pressure surfaces

\item Wind vectors

\item Humidity

\item Cloud water

\item Precipitation

\item Potential vorticity

\end{itemize}



Vertical structures include:


\begin{itemize}

\item Surface layer

\item Troposphere

\item Stratosphere

\item Upper atmosphere

\end{itemize}
