\section{Satellite and Radar Data Layers}


ACF integrates remote sensing information.



Satellite products:


\begin{itemize}

\item Visible imagery

\item Infrared imagery

\item Water vapor channels

\item Atmospheric composition

\end{itemize}



Radar products:


\begin{itemize}

\item Reflectivity

\item Precipitation estimation

\item Storm structure

\item Wind measurements

\end{itemize}
