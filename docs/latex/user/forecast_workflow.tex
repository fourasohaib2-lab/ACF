The operational forecasting workflow follows:


\begin{equation}
Observation
\rightarrow
Assimilation
\rightarrow
Numerical Prediction
\rightarrow
AI Analysis
\rightarrow
Forecast
\rightarrow
Warning
\end{equation}



Operational steps:

\begin{enumerate}

\item Analyze observations

\item Evaluate model forecasts

\item Compare ensemble solutions

\item Validate AI guidance

\item Produce forecast products

\item Issue warnings

\end{enumerate}
