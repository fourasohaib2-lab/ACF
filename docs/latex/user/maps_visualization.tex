AWCI supports multiple atmospheric visualization layers.


Available meteorological fields include:


\begin{itemize}

\item Surface temperature

\item Atmospheric pressure

\item Wind velocity

\item Relative humidity

\item Precipitation

\item Cloud cover

\item Vertical profiles

\item Satellite imagery

\item Radar products

\end{itemize}



Three-dimensional visualization allows exploration of:

\begin{itemize}

\item Atmospheric layers

\item Jet streams

\item Storm structures

\item Cloud systems

\end{itemize}
