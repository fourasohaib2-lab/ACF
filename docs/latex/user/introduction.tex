The Atmospheric Weather Center Interface (AWCI) is the operational
visualization and decision-support environment of the Atmospheric
Complexity Framework.


AWCI provides meteorological experts with an integrated workspace
combining observations, numerical forecasts, artificial intelligence
products and atmospheric analysis tools.


The main objectives are:

\begin{itemize}

\item Real-time atmospheric monitoring

\item Forecast analysis

\item Severe weather detection

\item Multi-model comparison

\item Decision support

\end{itemize}
