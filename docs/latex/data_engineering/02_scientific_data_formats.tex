\section{Scientific Data Formats}


ACF supports international scientific data standards.



Main formats:


\begin{itemize}

\item NetCDF

\item GRIB

\item HDF5

\item Zarr

\item BUFR

\end{itemize}



Applications:


\begin{itemize}

\item Weather forecasting

\item Climate analysis

\item Satellite processing

\item Ocean modeling

\end{itemize}
