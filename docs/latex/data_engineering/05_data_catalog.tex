\section{Scientific Data Catalog}


The ACF catalog provides discovery and management of datasets.



Metadata includes:


\begin{itemize}

\item Dataset description

\item Spatial coverage

\item Temporal coverage

\item Variables

\item Quality information

\end{itemize}



Catalog functions:


\begin{itemize}

\item Search

\item Access control

\item Version management

\end{itemize}
