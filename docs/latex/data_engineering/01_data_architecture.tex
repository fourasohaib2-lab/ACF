\section{ACF Data Engineering Architecture}


The ACF data platform manages the complete lifecycle of
Earth system data.



The architecture contains:


\begin{itemize}

\item Data acquisition

\item Quality control

\item Storage

\item Processing

\item Distribution

\item Analytics

\end{itemize}



Data flow:


\[
Source
\rightarrow
Ingestion
\rightarrow
Storage
\rightarrow
Processing
\rightarrow
Knowledge
\]
