\section{Forecast Uncertainty}


Atmospheric prediction contains uncertainties caused by:


\begin{itemize}

\item Observation errors

\item Model errors

\item Initial condition uncertainty

\item Chaotic atmospheric behavior

\end{itemize}



ACF quantifies uncertainty using:


\begin{itemize}

\item Ensemble spread

\item Probabilistic forecasts

\item AI uncertainty estimation

\end{itemize}
