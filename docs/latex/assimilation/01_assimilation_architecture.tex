\section{ACF Data Assimilation Architecture}


Data assimilation combines observations with numerical model
information to produce the best estimate of the atmospheric state.



The analysis cycle is:


\begin{equation}
Background
+
Observations
\rightarrow
Analysis
\rightarrow
Forecast
\end{equation}



The ACF assimilation system contains:


\begin{itemize}

\item Observation processing

\item Quality control

\item Observation operator

\item Analysis algorithm

\item Forecast initialization

\end{itemize}
