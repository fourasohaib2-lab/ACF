\section{Observation Operator}


The observation operator transforms the model state into
observation space.


\begin{equation}
y=H(x)
\end{equation}


where:


\begin{itemize}

\item $x$ is the model state

\item $H$ is the observation operator

\item $y$ is the simulated observation

\end{itemize}



Examples:


\begin{itemize}

\item Satellite radiances

\item Radar reflectivity

\item Surface temperature

\item Wind observations

\end{itemize}
