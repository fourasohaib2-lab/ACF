\section{HPC Workflow Orchestration}


ACF automates scientific workflows on HPC infrastructures.



Workflow management:


\begin{itemize}

\item Job scheduling

\item Resource allocation

\item Simulation control

\item Automatic monitoring

\end{itemize}



Operational workflow:


\[
Prepare
\rightarrow
Compute
\rightarrow
Validate
\rightarrow
Publish
\]
