\section{Parallel Computing Framework}


ACF uses parallel computing techniques to accelerate
Earth system simulations.



Parallel technologies include:


\begin{itemize}

\item Message Passing Interface (MPI)

\item Open Multi-Processing (OpenMP)

\item Distributed computing

\item Task parallelism

\item Data parallelism

\end{itemize}



Parallel execution model:


\[
Multiple\ Processors
\rightarrow
Shared\ Simulation
\rightarrow
Faster\ Prediction
\]


Applications:


\begin{itemize}

\item Numerical Weather Prediction

\item Climate modelling

\item Data assimilation

\item Artificial intelligence training

\end{itemize}
