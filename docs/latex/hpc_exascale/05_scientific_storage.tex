\section{Scientific Storage Infrastructure}


ACF manages large volumes of Earth observation and simulation
data.



Storage architecture:


\begin{itemize}

\item High speed storage

\item Scientific data lake

\item Long term archive

\item Distributed databases

\end{itemize}



Supported datasets:


\begin{itemize}

\item Satellite observations

\item Radar data

\item Model outputs

\item Climate archives

\end{itemize}
