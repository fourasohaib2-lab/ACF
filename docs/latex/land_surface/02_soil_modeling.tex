\section{Soil Modeling}


ACF represents soil properties and their evolution.



Parameters:


\begin{itemize}

\item Soil temperature

\item Soil moisture

\item Soil texture

\item Soil carbon

\item Nutrient content

\end{itemize}



Soil water balance:


\[
\Delta S=P-ET-R
\]


where:


\begin{itemize}

\item P : precipitation

\item ET : evapotranspiration

\item R : runoff

\end{itemize}
