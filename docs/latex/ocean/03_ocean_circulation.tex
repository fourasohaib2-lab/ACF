\section{Ocean Circulation Dynamics}


ACF models ocean circulation from surface to deep ocean.



Processes:


\begin{itemize}

\item Surface currents

\item Thermohaline circulation

\item Upwelling

\item Downwelling

\item Ocean transport

\end{itemize}



Ocean dynamics equation:


\[
\frac{DU}{Dt}
=
-\frac{1}{\rho}\nabla P
+
F
\]
