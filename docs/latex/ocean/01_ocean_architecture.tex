\section{ACF Ocean System Architecture}


The ACF ocean module represents the physical state and evolution
of the global ocean system.



The architecture integrates:


\begin{itemize}

\item Ocean observations

\item Numerical ocean models

\item Satellite measurements

\item Marine forecasting systems

\item Atmosphere-ocean coupling

\end{itemize}



Ocean workflow:


\begin{equation}
Observation
\rightarrow
Assimilation
\rightarrow
Ocean Model
\rightarrow
Forecast
\end{equation}
