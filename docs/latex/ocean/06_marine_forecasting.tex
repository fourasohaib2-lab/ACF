\section{Marine Forecasting}


ACF produces operational marine forecasts.



Products:


\begin{itemize}

\item Ocean currents

\item Wave forecasts

\item Storm surge

\item Sea temperature

\item Marine hazards

\end{itemize}



Users:


\begin{itemize}

\item Maritime services

\item Fisheries

\item Offshore industry

\item Coastal authorities

\end{itemize}
