\section{Air Quality Forecasting}


ACF produces operational air quality forecasts.



Forecast parameters:


\begin{itemize}

\item PM2.5

\item PM10

\item Ozone

\item NO2

\item SO2

\item CO

\end{itemize}



Applications:


\begin{itemize}

\item Health protection

\item Urban monitoring

\item Pollution alerts

\end{itemize}
