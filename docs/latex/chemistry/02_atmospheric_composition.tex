\section{Atmospheric Composition}


ACF monitors the chemical components of the atmosphere.



Main species:


\begin{itemize}

\item Oxygen ($O_2$)

\item Nitrogen ($N_2$)

\item Carbon dioxide ($CO_2$)

\item Methane ($CH_4$)

\item Ozone ($O_3$)

\item Nitrogen oxides ($NO_x$)

\item Sulfur dioxide ($SO_2$)

\item Carbon monoxide ($CO$)

\end{itemize}



Chemical concentration:


\[
C=\frac{mass}{volume}
\]
