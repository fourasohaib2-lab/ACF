\section{Aerosol Processes}


Aerosols influence weather, climate and air quality.



ACF represents:


\begin{itemize}

\item Dust particles

\item Sea salt

\item Smoke

\item Sulfates

\item Organic aerosols

\end{itemize}



Effects:


\begin{itemize}

\item Radiation modification

\item Cloud formation

\item Visibility reduction

\item Health impacts

\end{itemize}
