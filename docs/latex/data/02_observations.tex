\section{Atmospheric Observation Systems}


ACF integrates multiple observation networks.



\subsection{Satellite Observations}


Examples:


\begin{itemize}

\item Meteorological satellites

\item Earth observation missions

\item Atmospheric composition sensors

\end{itemize}



\subsection{Surface Observations}


Includes:


\begin{itemize}

\item Weather stations

\item Automatic stations

\item Marine observations

\item Aircraft measurements

\end{itemize}



\subsection{Remote Sensing}


ACF supports:


\begin{itemize}

\item Weather radar

\item Lidar

\item GPS atmospheric measurements

\end{itemize}
