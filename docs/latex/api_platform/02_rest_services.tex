\section{REST and Real Time Services}


ACF provides machine-accessible services.



Supported interfaces:


\begin{itemize}

\item REST API

\item WebSocket streaming

\item Message queues

\item Scientific data endpoints

\end{itemize}



Example services:


\begin{itemize}

\item Current weather state

\item Forecast products

\item Alert information

\item Satellite observations

\item Model outputs

\end{itemize}
