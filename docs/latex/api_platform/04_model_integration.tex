\section{External Model Integration}


ACF can connect external numerical models.



Supported models:


\begin{itemize}

\item WRF

\item ICON

\item IFS

\item AROME

\item Regional climate models

\end{itemize}



Integration mechanisms:


\begin{itemize}

\item Data adapters

\item Model wrappers

\item Workflow engines

\end{itemize}
