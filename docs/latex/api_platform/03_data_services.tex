\section{Scientific Data Services}


ACF exposes standardized scientific datasets.



Supported data:


\begin{itemize}

\item GRIB2 forecasts

\item NetCDF datasets

\item BUFR observations

\item Satellite products

\item Radar composites

\end{itemize}



Data services support:


\begin{itemize}

\item Querying

\item Filtering

\item Conversion

\item Visualization

\end{itemize}
