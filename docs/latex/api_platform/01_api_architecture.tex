\section{ACF Global API Architecture}


The ACF API platform provides standardized access to Earth
system information and computational services.



The architecture contains:


\begin{itemize}

\item API Gateway

\item Data services

\item Model services

\item Authentication layer

\item External integration layer

\end{itemize}



General architecture:


\begin{equation}
User
\rightarrow
API
\rightarrow
Services
\rightarrow
Data
\rightarrow
Models
\end{equation}
