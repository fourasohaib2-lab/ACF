\section{ACF Security Architecture}


The ACF security architecture protects scientific data,
computational resources and operational services.



The security framework includes:


\begin{itemize}

\item Identity management

\item Access control

\item Data protection

\item Network defense

\item System monitoring

\item Incident response

\end{itemize}



Security lifecycle:


\[
Protect
\rightarrow
Detect
\rightarrow
Respond
\rightarrow
Recover
\]
