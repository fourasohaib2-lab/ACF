\section{Cloud Microphysics}


Cloud processes include:


\begin{itemize}

\item Cloud water

\item Cloud ice

\item Rain

\item Snow

\item Graupel

\item Hail

\end{itemize}



The hydrometeor mixing ratios are represented by:


\begin{equation}
q_x
\end{equation}


where $x$ represents each hydrometeor category.
