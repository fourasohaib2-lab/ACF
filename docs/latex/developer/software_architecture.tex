\section{ACF Python Architecture}


The ACF software follows a modular architecture.


Main source tree:


\begin{verbatim}

src/acf/

acf_core
acf_gui
acf_data
acf_models
acf_ai
acf_maps
acf_analysis
acf_alerts
acf_reports
acf_api
acf_plugins

\end{verbatim}



\section{Design Principles}


The architecture follows:

\begin{itemize}

\item Modularity

\item Extensibility

\item Scientific reproducibility

\item Separation of concerns

\item Plugin-based development

\end{itemize}
