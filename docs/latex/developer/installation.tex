The ACF development environment is based on Python scientific
computing technologies.


\section{Required Environment}

Recommended system:

\begin{itemize}

\item Ubuntu Linux

\item Python 3.12+

\item Virtual environment

\item Scientific Python stack

\item Git version control

\end{itemize}



\section{Virtual Environment}


The recommended installation workflow:


\begin{verbatim}

python3 -m venv .venv

source .venv/bin/activate

pip install -r requirements.txt

\end{verbatim}



\section{Scientific Libraries}


ACF uses:

\begin{itemize}

\item NumPy

\item SciPy

\item Pandas

\item Xarray

\item NetCDF4

\item Cartopy

\item MetPy

\item Machine learning frameworks

\end{itemize}
