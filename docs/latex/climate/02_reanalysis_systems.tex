\section{Climate Reanalysis Systems}


Reanalysis combines historical observations with numerical
models to reconstruct the state of the Earth system.



ACF supports:


\begin{itemize}

\item Atmospheric reanalysis

\item Ocean reanalysis

\item Land surface reanalysis

\item Cryosphere datasets

\end{itemize}



Examples of applications:


\begin{itemize}

\item Climate monitoring

\item Extreme event analysis

\item Model validation

\item Trend estimation

\end{itemize}
