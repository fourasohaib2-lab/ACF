\section{Real Time Monitoring}


ACF continuously monitors atmospheric conditions.



Real-time products:


\begin{itemize}

\item Surface observations

\item Radar reflectivity

\item Satellite imagery

\item Lightning detection

\item Numerical forecasts

\end{itemize}



The monitoring system detects:


\begin{itemize}

\item Severe storms

\item Heat waves

\item Flood risks

\item Strong winds

\item Atmospheric anomalies

\end{itemize}
