\section{Multi Hazard Warning System}


ACF integrates a global hazard detection framework.



Supported hazards:


\begin{itemize}

\item Thunderstorms

\item Floods

\item Heat waves

\item Drought

\item Tropical cyclones

\item Severe winds

\item Space weather events

\end{itemize}



Warnings are generated using:


\begin{itemize}

\item Observations

\item Numerical forecasts

\item AI predictions

\item Risk analysis

\end{itemize}
