\section{Professional Forecaster Workstation}


The ACF workstation provides meteorologists with advanced
analysis capabilities.



Main functions:


\begin{itemize}

\item Weather map analysis

\item Vertical sounding analysis

\item Ensemble forecast evaluation

\item Severe weather monitoring

\item Product generation

\end{itemize}



The workstation integrates:


\begin{itemize}

\item Numerical models

\item Satellite data

\item Radar data

\item AI guidance

\end{itemize}
