\section{Wind Components}


The atmospheric wind vector is:


\[
\vec{V}=(u,v,w)
\]


where:

\begin{itemize}

\item $u$ : zonal wind

\item $v$ : meridional wind

\item $w$ : vertical velocity

\end{itemize}



\section{Vorticity}


Relative vorticity:

\begin{equation}
\zeta =
\frac{\partial v}{\partial x}
-
\frac{\partial u}{\partial y}
\end{equation}


Applications:

\begin{itemize}

\item Cyclone detection

\item Severe weather analysis

\item Atmospheric circulation

\end{itemize}



\section{Coriolis Parameter}


The Coriolis parameter at latitude $\varphi$ is:

\begin{equation}
f = 2\Omega\sin\varphi
\end{equation}


where $\Omega = 7.2921 \times 10^{-5}~\mathrm{rad\,s^{-1}}$ is Earth's
angular rotation rate. Geostrophic balance then gives:

\begin{equation}
u_g = -\frac{1}{f\rho}\frac{\partial p}{\partial y},
\qquad
v_g = \frac{1}{f\rho}\frac{\partial p}{\partial x}
\end{equation}
