\section{Wind Components}


The atmospheric wind vector is:


\[
\vec{V}=(u,v,w)
\]


where:

\begin{itemize}

\item $u$ : zonal wind

\item $v$ : meridional wind

\item $w$ : vertical velocity

\end{itemize}



\section{Vorticity}


Relative vorticity:

\begin{equation}
\zeta =
\frac{\partial v}{\partial x}
-
\frac{\partial u}{\partial y}
\end{equation}


Applications:

\begin{itemize}

\item Cyclone detection

\item Severe weather analysis

\item Atmospheric circulation

\end{itemize}
