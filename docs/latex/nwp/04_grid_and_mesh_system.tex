\section{Grid and Mesh System}


The ACF NWP system supports multiple computational grids.



Grid configurations:


\begin{itemize}

\item Global Earth grid

\item Regional high resolution grid

\item Local convection permitting grid

\item Adaptive mesh refinement

\end{itemize}



The horizontal resolution determines forecast detail:


\[
Resolution=\frac{Domain}{Number\ of\ Cells}
\]



Vertical representation:


\begin{itemize}

\item Pressure levels

\item Hybrid sigma-pressure coordinates

\item Terrain following coordinates

\end{itemize}



The system supports:


\begin{itemize}

\item Global forecasting

\item Regional forecasting

\item Severe weather simulation

\end{itemize}
