\section{Ensemble Prediction System}


The ACF Ensemble Prediction System (EPS) estimates forecast
uncertainty.



Instead of one forecast, multiple simulations are produced.



The ensemble contains:


\begin{itemize}

\item Different initial states

\item Different model physics

\item Different perturbations

\item Multiple forecast scenarios

\end{itemize}



The probability distribution is:


\[
P(X,t)
\]


ACF EPS provides:


\begin{itemize}

\item Probability forecasts

\item Risk estimation

\item Extreme event prediction

\item Forecast confidence

\end{itemize}
