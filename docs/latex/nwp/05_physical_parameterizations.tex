\section{Physical Parameterizations}


Processes smaller than the model grid are represented using
physical parameterizations.



ACF includes:


\begin{itemize}

\item Cloud microphysics

\item Convection schemes

\item Radiation processes

\item Boundary layer turbulence

\item Surface interactions

\item Land processes

\end{itemize}



Examples of parameterized processes:


\begin{equation}
Physical\ Process
\rightarrow
Mathematical\ Approximation
\end{equation}



Main components:


\begin{itemize}

\item Microphysics scheme

\item Cumulus scheme

\item Radiation scheme

\item Turbulence scheme

\end{itemize}
