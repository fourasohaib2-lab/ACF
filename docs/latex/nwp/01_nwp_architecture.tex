\section{ACF Numerical Weather Prediction Architecture}


The ACF Numerical Weather Prediction (NWP) system is the core
forecasting engine of the Atmospheric Complexity Framework.



The system integrates:


\begin{itemize}

\item Atmospheric dynamics

\item Physical parameterizations

\item Data assimilation

\item Numerical solvers

\item Ensemble prediction

\item Artificial intelligence

\end{itemize}



Operational workflow:


\[
Observation
\rightarrow
Assimilation
\rightarrow
NWP Model
\rightarrow
Forecast
\rightarrow
Products
\]
