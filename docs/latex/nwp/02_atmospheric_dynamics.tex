\section{Atmospheric Dynamics}


The atmospheric model solves the fundamental equations
governing fluid motion.



Primitive equations:


\[
\frac{DU}{Dt}
=
-\frac{1}{\rho}\nabla p
+
F
\]



The model represents:


\begin{itemize}

\item Momentum conservation

\item Mass conservation

\item Energy conservation

\item Moisture transport

\end{itemize}
