\section{Real Time Simulation}


ACF aims to provide continuous Earth system simulation.


The operational cycle includes:


\begin{enumerate}

\item Data acquisition

\item Quality control

\item Assimilation

\item Model integration

\item AI enhancement

\item Product generation

\end{enumerate}



The simulation frequency depends on:


\begin{itemize}

\item Available computing resources

\item Forecast requirements

\item Data latency

\end{itemize}
