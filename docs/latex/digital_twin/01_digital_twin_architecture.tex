\section{ACF Digital Twin Architecture}


The Atmospheric Complexity Framework implements a global Earth
system digital twin capable of continuously representing the
state of the planet.


The digital twin combines:


\begin{itemize}

\item Real observations

\item Numerical models

\item Artificial intelligence

\item Data assimilation

\item High performance computing

\item Visualization systems

\end{itemize}



The digital twin cycle:


\begin{equation}
Observation
\rightarrow
Assimilation
\rightarrow
Simulation
\rightarrow
Prediction
\rightarrow
Decision
\end{equation}
