\section{Coupled Earth System Models}


The Earth system requires interactions between multiple models.



Examples:


\begin{itemize}

\item Atmosphere model

\item Ocean circulation model

\item Land surface model

\item Sea ice model

\item Chemistry model

\end{itemize}



The coupled state is:


\begin{equation}
X_{Earth}
=
(X_a,X_o,X_l,X_i,X_b)
\end{equation}
