\section{Radar Observation Network}


Radar systems provide high resolution monitoring of
precipitation and severe weather.



ACF supports:


\begin{itemize}

\item Weather radar

\item Doppler radar

\item Dual polarization radar

\item Wind radar

\end{itemize}



Radar products:


\begin{itemize}

\item Reflectivity

\item Rainfall intensity

\item Storm structure

\item Wind velocity

\end{itemize}
