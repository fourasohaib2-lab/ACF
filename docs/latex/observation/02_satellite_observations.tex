\section{Satellite Observation System}


Satellites provide global and continuous Earth monitoring.



ACF integrates:


\begin{itemize}

\item Geostationary satellites

\item Polar orbiting satellites

\item Atmospheric composition satellites

\item Ocean observation satellites

\end{itemize}



Satellite measurements:


\begin{itemize}

\item Temperature profiles

\item Humidity

\item Cloud properties

\item Wind vectors

\item Radiation

\item Aerosols

\end{itemize}
