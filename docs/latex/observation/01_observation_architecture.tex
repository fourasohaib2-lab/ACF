\section{ACF Global Observation Architecture}


The ACF observation system provides continuous monitoring of
the Earth system.



The observation architecture integrates:


\begin{itemize}

\item Satellite platforms

\item Ground stations

\item Radar networks

\item Ocean observations

\item Aircraft measurements

\item Environmental sensors

\end{itemize}



Observation chain:


\[
Observation
\rightarrow
Quality Control
\rightarrow
Assimilation
\rightarrow
Prediction
\]
