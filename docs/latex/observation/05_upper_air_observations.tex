\section{Upper Air Observation System}


Upper air observations describe the three dimensional state
of the atmosphere.



Systems:


\begin{itemize}

\item Radiosondes

\item Aircraft observations

\item Wind profilers

\item Lidar systems

\end{itemize}



Measured variables:


\begin{itemize}

\item Temperature

\item Humidity

\item Wind profiles

\item Pressure

\end{itemize}
