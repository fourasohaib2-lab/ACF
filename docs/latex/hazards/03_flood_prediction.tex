\section{Flood Prediction System}


Flood forecasting combines atmospheric and hydrological models.



Inputs:


\begin{itemize}

\item Precipitation forecasts

\item Soil moisture

\item River observations

\item Terrain information

\item Satellite measurements

\end{itemize}



The system estimates:


\begin{itemize}

\item Flood probability

\item Water level evolution

\item Impact zones

\end{itemize}
