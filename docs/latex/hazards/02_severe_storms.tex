\section{Severe Storm Prediction}


ACF detects severe convective systems using:


\begin{itemize}

\item CAPE

\item CIN

\item Vertical wind shear

\item Helicity

\item Radar observations

\item Satellite imagery

\end{itemize}



Important indicators:


\begin{equation}
Risk=f(CAPE,Shear,Moisture)
\end{equation}



Applications:

\begin{itemize}

\item Thunderstorm warnings

\item Hail prediction

\item Tornado potential

\end{itemize}
