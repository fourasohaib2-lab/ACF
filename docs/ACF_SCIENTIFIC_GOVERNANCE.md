# ACF SCIENTIFIC GOVERNANCE (ACF-G001)

## 1. SCIENTIFIC REVIEW & VALIDATION METHODOLOGY

- **Physical Conservation Laws**: Mass, energy, momentum, and moisture conservation checks required for all numerical atmospheric solvers.
- **Reference Comparison**: Verification against ERA5 reanalysis, ECMWF IFS, and Météo-France ARPEGE/AROME operational outputs.
- **Reproducibility**: Identical seed and initial condition configuration must produce bit-reproducible forecast trajectories across cluster nodes.
