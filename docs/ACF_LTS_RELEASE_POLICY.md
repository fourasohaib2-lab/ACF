# ACF LTS RELEASE POLICY (ACF-LTS-001)

## 1. SEMANTIC VERSIONING & PATCH LIFECYCLE

- **LTS Patch Releases**: Issued as `v1.0.x` (e.g., `v1.0.1`, `v1.0.2`) containing non-breaking bug fixes and performance optimizations.
- **ADR / RFC Change Gate**: Any modification altering existing module interfaces or public method signatures requires ARB approval via ADR/RFC protocol.
- **Maintenance Duration**: 36 months of guaranteed support for ACF v1.0.0 LTS.
