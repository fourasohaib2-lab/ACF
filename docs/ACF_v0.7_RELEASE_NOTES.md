# ACF v0.7 RELEASE NOTES

**Release Version:** v0.7.0  
**Release Date:** August 6, 2026  

---

## 🚀 Key Highlights & New Capabilities

1. **NWP Verification Engine (`NWPVerificationMetrics`)**:
   - Automated computation of continuous metrics (RMSE, MAE, BIAS, ACC) and categorical event scores (ETS, CSI, POD, FAR) for 11 key atmospheric variables (T2M, U10M, V10M, MSLP, RH2M, RR24, Z500, T850, U250, V250, Q700).
2. **ESOC Forecast Verification Center (`NWPForecastCenterPanel`)**:
   - Interactive PySide6 dashboard for scorecards, verification score time-evolution graphs, and inter-model comparison tables.
3. **Automated Verification Reports**:
   - Standardized JSON verification scorecard exports and archival.
