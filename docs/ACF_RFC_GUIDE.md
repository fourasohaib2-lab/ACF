# ACF REQUEST FOR CHANGE (RFC) GUIDE (ACF-G001)

## 1. RFC PROCESS & TEMPLATE

New feature requests or major scientific additions must follow the RFC process:

```markdown
# RFC-XXX: [Feature Title]

**Proposer:** [Name / Role]  
**Target Version:** [e.g. v0.8, v1.0]  
**Status:** Draft / Review / Approved / Rejected  

### 1. Abstract
### 2. Scientific & Technical Rationale
### 3. Detailed Specification
### 4. Backwards Compatibility & Migration Path
```
