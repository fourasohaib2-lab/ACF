# ACF ARCHITECTURE DECISION RECORD (ADR) GUIDE (ACF-G001)

## 1. ADR TEMPLATE & WORKFLOW

Every architectural decision modifying the frozen baseline must submit an ADR following this template:

```markdown
# ADR-XXX: [Short Descriptive Title]

**Status:** Proposed / Accepted / Rejected / Deprecated  
**Date:** YYYY-MM-DD  
**Author:** [Name / Role]  

### Context
[Describe the problem or context prompting the decision]

### Decision
[Describe the chosen architectural solution]

### Consequences
[List positive and negative consequences, impacts on APIs or performance]
```
